## 🚀 How to Host Online for FREE from GitHub

You can publish this project online immediately using either **GitHub Pages**, **Vercel / Netlify**, or a **Live WordPress Host**:

### Option 1: 🌐 Host Free on GitHub Pages (1-Click Static Deployment)

1. Open your repository on **GitHub.com**.
2. Go to **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and set folder to `/(root)`.
4. Click **Save**.
5. Within 1-2 minutes, your website will be live at:
   ```
   https://<your-username>.github.io/<your-repo-name>/
   ```

---

### Option 2: ⚡ Host Free on Vercel or Netlify (Fast Global CDN)

1. Go to [Vercel.com](https://vercel.com) or [Netlify.com](https://netlify.com) and log in with your GitHub account.
2. Click **Add New Project** ➔ **Import Git Repository**.
3. Select this repository.
4. Leave settings as default and click **Deploy**.
5. Your custom live URL will be ready in under 30 seconds with automatic SSL and fast global CDN!

---

### Option 3: 🏷️ Deploy on Live WordPress (WooCommerce)

If you want the full WordPress backend with WooCommerce orders, customer logins, and live payment gateways (Stripe, PayPal, Cash on Delivery):

1. Download `aura-skincare-theme.zip` from this repository (or from the `wordpress-theme/` folder).
2. Log into your live WordPress Admin (`yourdomain.com/wp-admin`).
3. Go to **Appearance** ➔ **Themes** ➔ **Add New Theme** ➔ **Upload Theme**.
4. Choose `aura-skincare-theme.zip` and click **Install Now** ➔ **Activate**.
5. Install and activate the **WooCommerce** plugin.
6. Configure your menus in **Appearance ➔ Menus** and customize all banners and text in **Appearance ➔ Customize ➔ Aura Skincare Settings**.
